# ASMR Production Suite

Personal fragrance-production toolkit for **ASMR** — a signature luxury skin scent
produced in three formats (EDP/Extrait, mists, creams) from one shared concentrate.

Everything lives in one Excel workbook, **`ASMR_Production_Suite.xlsx`**, generated by
Python. Every output in the workbook is a **live Excel formula** — change any champagne-colored
input cell inside Excel and the whole workbook updates. Python is only needed to *regenerate*
the file from scratch.

## Files

| File | Purpose |
|---|---|
| `build_workbook.py` | Regenerates the workbook (openpyxl only), recalcs via Excel, then distributes. |
| `check_workbook.py` | Acceptance tests — runs on a copy, never touches your data. |
| `distribute.py` | Creates a permanent `Perfume NNN` version folder (local + Drive) and refreshes the latest copies. |
| `build_guide.js` | Regenerates the Master Method document (`$env:NODE_PATH=(npm root -g); node build_guide.js`). |
| `tools/excel_recalc.ps1` | Helper that makes Excel recalculate a file. |
| `ASMR_Production_Suite.xlsx` | The canonical workbook (latest). |
| `ASMR Perfume.xlsx` | Renamed duplicate — always the latest. |
| `ASMR Perfume - Master Method.docx` | The production masterclass: master-batch method, step by step, ingredient by ingredient. |
| `Originals/` | Frozen first release. Never overwritten. |
| `Revisions/` | Legacy timestamped snapshots — kept, no longer written. |
| `Perfume 001/`, `Perfume 002/`… | Permanent numbered versions — one per build, never overwritten. |

**Everything is mirrored to `G:\My Drive\ASMR\`** — same structure. Google Drive for
Desktop syncs it to the cloud automatically.

## Versioning rule (runs automatically on every build)

`build_workbook.py` finishes by recalculating the workbook (so saved copies open with
values) and calling `distribute.main()`, which:

1. Seeds `Originals/` if it is empty (first release only).
2. Creates the next permanent folder `Perfume NNN` — locally **and** on Drive — holding
   `ASMR Perfume NNN.xlsx`, `ASMR Perfume - Master Method NNN.docx`,
   `README NNN.md` and `Version Info NNN.txt`. Existing version folders are never touched.
3. Refreshes the unnumbered "latest" files at both roots (non-fatal if one is open in Excel —
   the permanent version folder is already safe).

Run `python distribute.py` alone to cut a new version without rebuilding.

## Production method (the standard)

ASMR is produced by **master batch**: one 42.5 g concentrate for a 250 ml EDP run
(Batch Calculator @ 250 ml), one marriage, one maceration vessel filled to the shoulder,
one cold-crash + filtration — then divided into bottles **by weight** (42.5 g per 50 ml).
The complete technique, ingredient-by-ingredient handling notes and tricks are in
`ASMR Perfume - Master Method.docx`.

## How to run

```
python build_workbook.py     # regenerates the workbook AND mirrors to local + Drive
python check_workbook.py     # runs the 50 acceptance checks (needs Excel installed)
python distribute.py         # re-mirror local + Drive without rebuilding
```

> ⚠ `build_workbook.py` recreates the workbook **from defaults** — your Production Log
> and Inventory edits live in the xlsx, so back it up before regenerating.

Sheets are protected (no password) so formulas can't be broken by accident;
champagne/gold cells are unlocked inputs. Unprotect any sheet from
Review → Unprotect Sheet if you need to restructure.

## The tabs

1. **Dashboard** — capital, stock value, concentrate cost/g, batch quick-launch,
   low-stock alerts, next maceration milestones. Read-only.
2. **Formula Master** — the 25-material formula. Edit `Input %` to tweak the accord.
   The `Include optionals` toggle (YES/NO) removes Irone Alpha + Javanol and
   renormalizes everything else to 100% automatically. The message row must always
   read “✓ BALANCED”.
3. **Batch Calculator** — *the core*. Opens preset to **Eau de Parfum @ 20%**
   (the signature long-lasting default); pick any format, size (ml or g), concentrate %,
   density. It outputs every material in weighing order (BASE → HEART → TOP), the
   D10-dilution vs neat grams, solvent/auxiliary grams, checksum rows, batch cost and
   cost/ml. **Print it** — the print area is a one-page A4 bench sheet with tick boxes.
4. **Dilution Prep (D10)** — the five 10%-in-DPG dilutions (default 10 g = 1 g neat + 9 g DPG),
   with date-made and remaining-grams tracking.
5. **Inventory** — packs, editable densities (ml→g), price/g, grams on hand
   (live: purchases − usage from the Production Log). Rows turn **red** when stock falls
   below two default batches. Yellow cells (DPG pack, alcohol bottle) are assumed sizes — edit them.
6. **Production Log** — one row per batch. This drives inventory depletion and the tracker.
7. **Maceration Tracker** — auto-view: days elapsed/remaining, amber < 2 weeks,
   green ≥ 4 weeks (ready window 4–8 weeks).
8. **Cost Analysis** — capital incl. the 351 SAR shipping (allocated proportionally),
   concentrate cost/g, cost per bottle at common sizes, remaining stock value.
8b. **Yield & Capacity** — how many bottles your current stock can make, for sizes
   10 / 20 / 30 / 50 / 70 / 100 ml. Fully live: reads Inventory on-hand grams and the
   Formula Master percentages, so counts drop as you log batches. Shows which material
   runs out first (the bottleneck), a material-by-material capacity table, and cost per
   bottle. Inputs: concentrate % (20% EDP default), density, bench-loss %, and a
   stock basis toggle (On hand vs Purchased).
8c. **Pricing & Sales** — cost → retail for the bottles you sell (Extrait only). Live juice
   cost from Cost Analysis + your editable packaging, labour, target multiple and 15% VAT.
   Shows retail ex-/inc-VAT, profit per bottle, a 2×/2.5×/3×/4× reference, and batch
   economics. Includes a "before you sell" panel (IFRA, SFDA registration, VAT, labelling).
9. **Process Reference** — bench SOPs for all six product routes.
10. **Safety Notes** — read before every session. Non-negotiables: Bergamot **Accord**
    on skin (the EO is phototoxic — fabric only), one amber material, preservative in every
    water-containing product, cream fragrance ≤ 1.2%, weigh in grams never drops.

## How to log a batch

1. Set up the batch in **Batch Calculator**; print the bench sheet; weigh and blend.
2. On **Production Log**, fill one row: date, batch ID (e.g. `ASMR-20260709-01`),
   format, size, conc %, and copy **Concentrate (g)** and **Alcohol (g)** from the calculator.
3. Enter the maceration start date — the target end (start + 42 days, editable) fills itself.
   Set status to *Macerating*.
4. That's it. Inventory grams-on-hand drop, the Maceration Tracker starts counting,
   and the Dashboard shows your next milestone. When you filter and bottle, update the status.

## Acceptance tests (all passing)

1. Formula sums to 100.00% with optionals ON, and renormalized to 100.00% with optionals OFF.
2. EDP 50 ml @ 20%, density 0.85 → 42.5 g total, 8.5 g concentrate, materials sum ±0.01 g, 34 g alcohol.
3. Water mist 100 g @ 2.5%, 4× solubilizer → 2.5 / 10 / 2.5 / 0.8 / 84.2 g = 100 g.
4. Cream Route 2 at 100 g sums to exactly 100 g.
5. Logging a batch depletes Inventory (incl. D10 neat-vs-DPG split and alcohol).
6. No formula errors anywhere (verified with a real Excel recalculation).
