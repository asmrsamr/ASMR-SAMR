## 4. A6 Printable Batch Card Design Brief

To be printed on high-density 350gsm warm ivory cardstock with a rough cotton texture. Included in every order box.

### Layout Guidelines
- **Card Size:** A6 (105mm x 148mm), Portrait.
- **Color Palette:** Warm Ivory background, deep graphite charcoal text, blind-embossed or gold-foiled batch frame.
- **Font Stack:** Instrument Serif (large Display titles) and Plus Jakarta Sans (fine details and body copy).

```
+------------------------------------------+
|                                          |
|            ASMR & SAMR                   |
|                                          |
|            - - - - - -                   |
|                                          |
|            BATCH B.077                   |
|                                          |
|          BOTTLE NO. ____ / 158           |
|                                          |
|            Hand-numbered                 |
|                                          |
|            RIYADH, S.A.                  |
|                                          |
+------------------------------------------+
```

### Front Design
1. **Header:** Minimalist brand wordmark `ASMR & SAMR` centered at the top.
2. **Center Graphic:** Clean thin box containing the batch number `B.077`.
3. **Numbering Section:** Under the batch box, the handwritten numbering field:
   `Bottle No. ________ / 158` (The specific bottle number is filled by hand by the perfumer using a metallic gold marker).
4. **Locality:** `Hand-poured and matured in Riyadh, Saudi Arabia.`
